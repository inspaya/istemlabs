## Objective
The first part of the beginner course builds on previous knowledge gained in the foundation course while also helping students understand the key elements of software development for the web. Students are engaged in real-world software projects with the aim of publishing their first creation.

<a target="_blank" href="https://tinyurl.com/6kmnrzc6">Click here to register</a>

## Duration
This course runs for a total duration of 22 hours (21 paid hours + 1 FREE hour).

## Prerequisites
To participate in this course, students must demonstrate competence in the following concepts:

1. Using the command line/terminal/shell

1. Using a text editor and/or Integrated Development Environment (I.D.E)

1. Using Git commands and setting up a repository on Github.com, Bitbucket.org, Gitlab.com or a similar cloud-based VCS platform.

## Certification
Upon successful completion of this course, participants will be awarded the **iSTEMLabsAfrica Software Engineering: Beginner Course I** certificate.

## Cost
The cost of this course is N42,000 (Fourty-Two Thousand Only)

## Course Content
 1. 1hr - iSTEMLabsAfrica Digital Awareness Health Check (FREE)
 1. 4hrs - Essential HTML and CSS 
    * HTML Fundamentals
       - HTML 5 improvements
       - Basic tags and elements, Headings, Paragraphs, Lists
       - Semantic HTML introduction
       - Tables and forms
       - Exercises: First HTML page
    * CSS overview
       - Basic directives
         - Introduction
         - Syntax
         - Selectors
         - How to
         - Commenting
         - Box-Model: Borders, Margins, Padding, Height/Width
         - Text and Fonts
         - Pseudo-elements
         - Backgrounds and Images
         - CSS opacity
         - CSS Layout: float, inline, inline-block
       - Using Bootstrap
 1. 2hrs - Project A: The student is tasked with building a correctly-styled website using the Bootstrap CSS package.
 1. 4hrs - Essential Javascript
    * Comments, Variables and Operators
    * Data Types and sample operations allowed
    * Conditionals and Loops
    * Functions and Events
 1. 2hrs - Project B: The student is tasked with upgrading the static website to a functional website using Javascript
 1. 3hrs - Publishing Websites for Free(Jekyll, GH Pages, Netlify, Wix)
    * https://www.rithmschool.com/courses/intermediate-css-bootstrap/github-pages
 1. 6hrs - Introduction to Web Applications
    * Understanding the Client-Side (Web Browser, Command-Line e.g. curl, e.t.c)
    * Understanding the Server-side
      - Web Servers
      - Application Servers
      - Programming Languages
      - Database Servers
      - REST API
 1. 2hrs - Capstone Project: Build a Website and Deploy it
