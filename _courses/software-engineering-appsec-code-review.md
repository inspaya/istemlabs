## Objective
In many software projects, deadlines are tight and several security best-practices are ignored in order to meet up. Often times, such software products delivered are vulnerable to malicous human/bot attackers. This course teaches the process of identifying, exploiting and fixing security flaws in software products with several hands-on labs and tools students can practice with.

## Prerequisites
To participate in this course, students are required to have familiarity with collaboration platforms like Github.com and/or Bitbucket.org. Basic familiarity with computer science concepts such as, what programming languages are, web and internet systems, operating systems, the ability to describe each of these items and give examples without necessarily knowing all the details of how they work is also considered beneficial. The ability to write code in one or more programming languages is a huge plus.

## Certification
