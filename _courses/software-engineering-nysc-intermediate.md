## Objective
This course builds on knowledge acquired from the NYSC Beginners course and dives deeper into additional concepts that help the student succeed as a Python Developer while exposing them to remote work opportunities. Emphasis is laid on hands-on projects that help students solidify their understanding of the language and different scenarios where it can be applied.
This course is part of our special arrangement with the National Youth Service Corps (N.Y.S.C) Skills And Entrepreneurship Development (S.A.E.D) department to provide discounted training for active Corps Members as a contribution to knowledge and skills acquisition for youths in Nigeria.

## Duration
This course runs for a total duration of 36 hours.

## Prerequisites
To participate in this course, students need to have a basic familiarity with computer science concepts, such as programming language definitions, web and internet systems, operating systems e.t.c. They should be able to describe each of these items and give examples without necessarily knowing all the details of how they work. In addition, basic familiarity with Linux, Version Control Software e.g. Git, Structured Query Language (SQL), at least one server-side programming language, and one or more RDBMS systems are required. Please note that verifiable, active enrollment in the National Youth Service Corps (N.Y.S.C) program is mandatory.

## Certification
Upon successful completion of this course, participants will be awarded the **iSTEMLabsAfrica Mid Level Developer (Corper Bootcamp) Certificate** certificate.

## Course Content
1. 1hr -  iSTEMLabsAfrica Digital Awareness Health Check (1 hr FREE)
   
1. 3hrs -  Introduction to Python
  - General overview of the language, syntax, features e.t.c., setting up a development environment, using virtual environments, package managers (pip, poetry) and writing your first program.

1. 3hrs - Data Structures (a.k.a Data Types) in Python
  - Using Primitives: integer, float, boolean, strings, using Non-Primitives: Lists, Dictionaries, Tuples, Sets

1. 3hrs -  Control, Repetition, Functions and more

1. 3hrs - Object-Oriented Programming (OOP) in Python I
  - Introduction to OOP concepts

1. 3hrs - Object-Oriented Programming (OOP) in Python II
  - Using classes, writing methods for classes, understanding scope
  - Recommended best practices (documentation)

1. 3hrs - Introduction to Unit Testing
  - Common Testing libraries (pytest, doctest)
  - Code test coverage

2. 3hrs - Working with Databases in Python
  - Python Database libraries
  - Build a sample Database application

1.  6hrs - Introduction to REST APIs
  - 1hr - Understanding HTTP Verbs and using Python to interact with them
  - 3hrs - Working in Python with JSON, CSV, YAML
  - 1hr - Building in Authentication

1.  5hrs - Using Development Frameworks (Django, Flask)
  - Building a simple Django project
  - Building a simple Flask project

1. 4hrs - Capstone Project
  - Fully functional web application deployed online.
