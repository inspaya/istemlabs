# Software Engineering: Foundation Course (SENG-101)

## Objective

The foundation course is designed to provide a solid introduction to the world of Software Engineering by exposing participants to core concepts, knowledge and skills required to succeed as Software Engineers.

## Duration

This course runs for a total duration of 27 hours (26 paid hours + 1 FREE hour).

## Prerequisites

To participate in this course, students only need to be familiar with how to operate a computer system, use the input devices such as keyboard and mouse, as well as be familiar with how to access information on the Internet.

## Certification

Upon successful completion of this course, participants will be awarded the “iSTEMLabsAfrica Software Engineering: Foundation Course” certificate.

Cost
The cost of this course is N52,000 (Fifty-Two Thousand Naira Only).
