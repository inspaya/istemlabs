## Objective

This course is designed to highlight the benefits of applying automated testing techniques to code. It explores common types of testing and how to integrate these into Continuous Integration/Continuous Deployment systems.

## Duration

This course runs for a total duration of 29 hours (28 paid hours + 1 FREE hour).

## Prerequisites

To participate in this course, students need to be familiar with at least one of the following programming languages: PHP, Python or Node.js (or JavaScript itself). Familiarity with the Linux environment is also a plus.

## Certification

Upon successful completion of this course, participants will be awarded the “iSTEMLabsAfrica Software Engineering: Software Tester ” certificate.
