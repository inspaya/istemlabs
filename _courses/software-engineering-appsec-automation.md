## Objective
The work required to secure a software system is often multi-faceted, repetitive, and sometimes laborious, which makes it error-prone when handled manually. Multiply these activities by multiple software systems and a nightmare comes to life. This course teaches participants how to identify opportunites for automating/operationalizing  common tasks in Application Security to ensure consistent results and reduce friction amongst stakeholders on a software system.

## Prerequisites
To participate in this course, students are required to **be proficient** in the use of collaboration platforms like Github.com and/or Bitbucket.org. In addition, above average familiarity with computer science concepts such as, programming languages, web and internet systems and operating systems. The ability to write code in one or more programming languages is **mandatory** for this course. [§]

[§] **Students who have completed/are familiar with the topics taught in the [Code Review](https://istemlabs.africa/software-engineering-track/appsec-code-review) course already meet these prerequisites.**
