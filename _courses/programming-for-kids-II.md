# Software Programming for Kids II

## Objective
This course builds on knowledge acquired in Programming for Kids I. Participants learn to instruct the computer using the Python programming language.

## Duration
This course runs for a total duration of 28 hours (27 paid hours + 1 FREE hour).

## Prerequisites
Successful completion of Programming for Kids I course

## Certification
Upon successful completion of this course, participants will be awarded the “iSTEMLabsAfrica Kids Coder II” certificate.

## Cost
The cost of this course is N27,000 (Twenty-Seven Thousand Naira Only).

## Course Content
1. iSTEMLabsAfrica Digital Awareness Healthcheck (1hr FREE)

1. 2hrs - Introduction to Computer Programming
1. 2hrs - Where to write code (IDLE and/or other setup) and our first program - Hello Python! (Writing and executing code, syntax rules, variables and values, filenames e.t.c.)
1. 2hrs - Project A: The student’s knowledge of basic python syntax is tested

1. 4hrs - Types of Data in Python
    - 2hrs - Primitive Data Types: str, int, boolean, and float in programs.
    - 2hrs - Non-Primitive Data Types: (i.e. list, tuple, range, dict) in programs
1. 1hr - Project B: The student’s knowledge of Data Types is tested

1. 4hrs - Making decisions in programs
1. 1hr - Project C: The student’s knowledge of decision making in programming is tested.

1. 4hrs - Repeating actions in programs
1. 1hr - Project D: The student's knowledge of using loops and iteration is tested

1. 4hrs -  Understanding functions
    - 2hrs - Built-in functions
    - 2hrs - Writing your own functions
1. 2hrs - Capstone Project
