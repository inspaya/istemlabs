## Objective

This course dives deeper into additional concepts that help the student succeed as a Python Developer. In this course, we explore several Python libraries that enhance the software development process and output. The course provides hands-on projects to help students solidify their understanding of the language and different scenarios where it can be applied.

## Duration

This course runs for a total duration of 34 hours ( 33 paid hours + 1 FREE hour).

## Prerequisites

To participate in this course, students need to have a basic familiarity with computer science concepts, such as programming language definitions, web and internet systems, operating systems e.t.c. They should be able to describe each of these items and give examples without necessarily knowing all the details of how they work. In addition, students need to be familiar with basic Python programming.

## Certification

Upon successful completion of this course, participants will be awarded the “iSTEMLabsAfrica Software Engineering: Mid-Level Developer II ” certificate.

## Course Content

1. 1hr - iSTEMLabsAfrica Digital Awareness Health Check (1 hr FREE)
2. 4hrs - Object-Oriented Programming (OOP) in Python II
   - 2hrs - Writing methods() for classes, understanding public/private methods and scope
   - 2hrs - Recommended practices (documentation)
3. 2hrs - Project A
4. 2hrs - Introduction to Unit Testing, pytest, doctest
5. 2hrs - Working with Databases
   - 1hr - Python Database libraries
   - 1hr - Example Database application
6. 2hrs - Project B
7. 8hrs - Introduction to REST APIs
   - 1hr - Understanding HTTP Verbs and using Python to interact with them
   - 3hrs - Working in Python with JSON, CSV, YAML
   - 4hrs - Building in Authentication
8. 2hrs - Project c
9. 8hrs - Using Development Frameworks (Django, Flask)
   - 4hrs - Building a simple Django project
   - 4hrs - Building a simple Flask project
10. 3hrs - Capstone Project
