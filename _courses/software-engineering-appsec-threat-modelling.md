## Objective
Threat Modeling is a proactive security techique where vulnerabilities in a system are identified and used as a guide to determine types of countermeasures to be introduced to prevent and/or mitigate the effects of such flaws. In this course, students engage in hands-on sessions during which they learn where best to apply fixes, and the necessary tradeoffs that need to be made vis-a-vis security needs.

## Prerequisites
To participate in this course, students are required to have basic familiarity with computer science concepts such as, what programming languages are, web and internet systems, operating systems, the ability to describe each of these items and give examples without necessarily knowing all the details of how they work is also considered beneficial. Familiarity with one more cyber attack techniques is a plus.
