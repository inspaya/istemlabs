## Objective
In many software projects, developers in their race to meet deadlines often ignore several security best-practices, which leaves their finished products vulnerable to malicous human/bot attackers. This course teaches the process of identifying, exploiting and fixing security flaws in software products with hands-on labs containing functional software.

## Prerequisites
To participate in this course, students are required to have familiarity with collaboration platforms like Github.com and/or Bitbucket.org is a plus. Basic familiarity with computer science concepts such as, what programming languages are, web and internet systems, operating systems, the ability to describe each of these items and give examples without necessarily knowing all the details of how they work is also considered beneficial.

## Certification
Participants who complete this course will be awarded the **CyberSecurity: Secure Code Reviewer** certificate.
